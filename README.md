# bendevshop_tabacjob
Job tabac ESX gratuit. Récolte de plantes, transformation en tabac et cigarettes, fabrication de paquets, vente à un PNJ et location de camion avec caution. Interface intégrée, notifications au choix, contrôles côté serveur, français et anglais. Compatible ox_inventory. Dépendances : es_extended, ox_lib, ox_target, oxmysql. Installation en 3 min.
